# e-plantShopping

Welcome to **e-plantShopping**, a vibrant and intuitive React-based e-commerce application dedicated to bringing nature closer to your home. This platform allows plant enthusiasts to browse through a curated selection of house plants, learn about their care, and seamlessly add them to a shopping cart.

---

## 🌿 Project Overview

The **e-plantShopping** application is designed to provide a smooth, responsive, and delightful shopping experience for users looking to buy plants online. Built with modern React concepts, this project showcases component-driven UI design, state management, and interactive user flows.

### Key Features
* **Curated Plant Catalog:** Browse plants categorized by type (e.g., air-purifying, low-maintenance) with clear pricing and visuals.
* **Interactive Shopping Cart:** Real-time updates showing the total number of items and cumulative cost as you add or remove plants.
* **Responsive UI:** A clean, modern, and aesthetically pleasing design optimized for various screen sizes.

---

## 🛠️ Technology Stack

* **Frontend Framework:** React.js
* **Styling:** CSS3 / Custom Styles
* **State Management:** React Hooks (`useState`, `useEffect`)
* **Version Control:** Git & GitHub
